================================================================================
                    TRAVONET-WG: СБОРНИК СТРАТЕГИЙ ДЕСИНХРОНИЗАЦИИ
================================================================================

Данный файл содержит набор стратегий обхода систем глубокого анализа пакетов (DPI / ТСПУ),
а также инструкции по их запуску через командную строку с чистым WireGuard-конфигом (.conf).

--------------------------------------------------------------------------------
1. КОМАНДЫ ЗАПУСКА: SOCKS5 С ROOT (СЫРЫЕ СОКЕТЫ И НАСТОЯЩАЯ L3-ФРАГМЕНТАЦИЯ)
--------------------------------------------------------------------------------

При запуске с правами root (sudo) TravonetWG автоматически открывает сырые L3-сокеты
(AF_INET, SOCK_RAW, IPPROTO_RAW с флагами IP_HDRINCL и IP_NODEFRAG). Это дает возможность
нарезать исходящий IP-пакет рукопожатия на физические фрагменты и инъецировать фейки.
При этом флаг --socks (или --socks5) поднимает локальный прокси без изменения системных маршрутов ОС.
Адрес и порт опциональны: если не указаны, используется 127.0.0.1:1080. Можно указать только порт (например, 1088) или полный адрес (0.0.0.0:1088).

Команда для запуска со стандартной проверенной стратегией и подробным логом:
  sudo ./travonet-wg -c warp.conf --socks -d

Команда с указанием кастомного порта:
  sudo ./travonet-wg -c warp.conf --socks 1088 -d

Команда с явным указанием стратегии и автоматическим подбором TTL:
  sudo ./travonet-wg -c warp.conf --socks 1080 -s "junk(64) -> fake_udp(148) -> frag(8) -> frag(148)" --fake-ttl auto -d

Команда с фиксированным TTL фейка (например, TTL=10 хопов):
  sudo ./travonet-wg -c warp.conf --socks 1080 -s "junk(64) -> fake_udp(148) -> frag(8) -> frag(148)" --fake-ttl 10 -d

Проверка работы SOCKS5 через curl (в соседнем терминале):
  curl -x socks5h://127.0.0.1:1080 https://cloudflare.com/cdn-cgi/trace
  (В выводе должно быть: warp=on)

Запуск без root (чистый userspace через setsockopt IP_TTL):
  ./travonet-wg -c warp.conf --socks -d

Запуск в качестве системного VPN (перенаправление всего интернета через TUN):
  sudo ./run_warp.sh warp.conf

--------------------------------------------------------------------------------
2. КАТАЛОГ СТРАТЕГИЙ (ПЕРЕДАЮТСЯ В АРГУМЕНТ -s ИЛИ --strategy)
--------------------------------------------------------------------------------

[Стратегия 1: По умолчанию, доказавшая 100% эффективность против ТСПУ]
  junk(64) -> fake_udp(148) -> frag(8) -> frag(148)

  Описание:
  1. junk(64): Отправляет 64-байтный псевдослучайный UDP-пакет перед рукопожатием,
     сбивая эвристики первого пакета сессии на ТСПУ.
  2. fake_udp(148): Отправляет фейковый пакет рукопожатия с сигнатурой 0x01 и коротким
     TTL (8-11 хопов). Пакет регистрируется в таблице сессий ТСПУ и умирает до сервера.
  3. frag(8): Настоящий первый фрагмент, содержащий только 8 байт заголовка UDP (порты).
  4. frag(148): Настоящий второй фрагмент, содержащий 148 байт полезной нагрузки
     WireGuard без заголовка UDP. ТСПУ не видит портов вместе с сигнатурой и пропускает пакет.

[Стратегия 2: Чистая фрагментация транспортного заголовка без фейков]
  frag(8) -> frag(148)

  Описание:
  Пакет разбивается на 8 байт UDP-заголовка и 148 байт полезной нагрузки.
  Используется, если магистральный фильтр блокирует только по сигнатуре внутри
  цельного UDP-пакета и не требует предварительного отравления кэша фейком.

[Стратегия 3: Pre-Junk + Чистая фрагментация]
  junk(64) -> frag(8) -> frag(148)

  Описание:
  Первый случайный пакет сбивает сопоставление протокола, после чего идет
  нарезанное легитимное рукопожатие.

[Стратегия 4: Фейк между фрагментами]
  frag(8) -> fake_udp(148) -> frag(148)

  Описание:
  Сначала отправляется фрагмент с заголовком UDP, следом инъецируется фейковый
  UDP-пакет с коротким TTL, а затем легитимное тело рукопожатия.

[Стратегия 5: Фрагментация с тайминговой паузой]
  junk(64) -> sleep(10ms) -> fake_udp(148) -> sleep(5ms) -> frag(8) -> frag(148)

  Описание:
  Добавляет микрозадержки между пакетами для обхода DPI с буферизацией временного окна.

[Стратегия 6: Инъекция фейкового фрагмента с коротким TTL]
  junk(64) -> fake_frag(offset=0, len=8, mf=true) -> frag(8) -> frag(148)

  Описание:
  Вместо цельного UDP-фейка отправляется фальшивый начальный фрагмент с пониженным TTL,
  после чего идут легитимные фрагменты.

[Стратегия 7: Стратегия для непривилегированного Userspace (без root)]
  junk(64) -> fake_udp(148)

  Описание:
  В пространстве пользователя без прав root ОС не разрешает отправку сырых IP-фрагментов.
  Движок TravonetWG использует динамическое переключение setsockopt(IP_TTL) на стандартном сокете:
  отправляет junk, затем фейковый пакет с низким TTL, затем восстанавливает нормальный TTL и
  отправляет настоящее рукопожатие.

--------------------------------------------------------------------------------
3. СИНТАКСИС КОМАНД DSL
--------------------------------------------------------------------------------

- junk(size, [badsum=bool]):
  Отправка мусорного UDP-пакета случайных байт заданного размера.

- fake_udp(size, [ttl=int]):
  Отправка фейкового UDP-пакета с заголовком WireGuard Initiation (байт 0x01)
  и указанным значением TTL. Если TTL не указан, используется глобальный FakeTTL.

- frag(offset, len, [mf=bool, ttl=int]):
  Отправка реального фрагмента легитимного пакета рукопожатия.
  offset=0, len=8 отправляет только заголовок UDP.

- fake_frag(offset, len, [mf=bool, ttl=int]):
  Отправка поддельного фрагмента с низким TTL.

- sleep(duration):
  Пауза между отправками (например, 5ms, 10ms, 50ms).

Оператор -> связывает звенья цепочки.
